# Sprites d'items (drop-in)

Dépose ici un PNG **nommé exactement comme l'id de l'item** → il remplace
automatiquement l'icône dessinée à la main, partout (sac, description, objet qui
jaillit du trou, ramassage au sol). Aucun code à toucher. Fichier absent = on
garde le joli dessin procédural (repli automatique).

- Format : PNG transparent, carré de préférence (redimensionné à ~42 px de côté à l'affichage).
- Exemples de noms : `couronneOr.png`, `idoleOr.png`, `coffret.png`, `bagueGemme.png`,
  `amuletteDragon.png`, `griffePhenix.png`, `noyauEnergie.png`, `talismanEtoile.png`,
  `clefDoree.png`, `medaillonSoleil.png`, `coeurCristal.png`, `eclatMeteore.png`,
  `etoileSherif.png`, `billeAgate.png`, `potionSoin.png`, `potionEnergie.png`, `dorureArc.png` (l'or).
- Finitions d'arc : `platingChrome.png`, `platingNeon.png`, `platingRubis.png`,
  `platingEmeraude.png`, `platingRoyal.png`.

## Où trouver de l'art libre

- **Ultimate Fantasy RPG Icon Pack** (CC0, peint à la main) —
  https://gaspardani87.itch.io/fantasy-rpg-icons — télécharge le zip, dépose les
  PNG ici en les renommant selon la liste ci-dessus.
- OpenGameArt (CC0) : https://opengameart.org/content/cc0-gem-icons
